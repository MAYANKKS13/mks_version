# mks_version 🎵

A music web application built using Angular, created as a fan project inspired by Taylor Swift's albums and music.

## About The Project

mks_version is a personalized music application where users can explore songs from different Taylor Swift albums, view album artwork, and listen to songs through an interactive web interface.

The idea behind this project was to combine my interest in music with my passion for development and create a complete frontend application from scratch.

This application was developed by me, including:

* Application structure and component design
* User interface design
* Album-wise organization
* Audio integration
* Asset management and deployment setup

## Features

* 🎧 Browse songs organized by albums
* 🖼️ Album artwork display
* ▶️ Play and pause songs directly from the application
* ⏹️ Automatically stops previously playing songs when another song starts
* 📱 Responsive user interface
* 🌐 Deployed and accessible through GitHub Pages

## Tech Stack

* **Frontend:** Angular
* **Language:** TypeScript
* **Markup & Styling:** HTML, CSS
* **Version Control:** Git & GitHub
* **Deployment:** GitHub Pages
