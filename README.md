# mks_version 🎵

A responsive Angular music player inspired by Taylor Swift albums, featuring album browsing, favorites, shuffle/repeat playback, and a custom music player.

## About The Project

mks_version is a music streaming-style web application built with Angular, inspired by Taylor Swift's discography. Users can browse songs album-wise, play music through a custom player, manage favorite songs, and enjoy features like shuffle, repeat, and responsive playback controls.

The idea behind this project was to combine my interest in music with my passion for development and create a complete frontend application from scratch.

This application was developed by me, including:

* Application structure and component design
* User interface design
* Album-wise organization
* Audio integration
* Asset management and deployment setup

## Features

* 🎧 Browse songs organized album-wise
* ▶️ Play, pause, previous, and next song controls
* 🔀 Shuffle mode for random song playback
* 🔁 Repeat mode for continuous listening
* ❤️ Mark songs as favorites (stored locally in browser)
* 🎵 Highlights the currently playing song
* 📀 Interactive music player with seek/progress bar
* 🖼️ Album artwork displayed for every song
* 📱 Fully responsive design for desktop and mobile devices
* 🌐 Deployed and accessible through GitHub Pages

## Tech Stack

* **Frontend:** Angular
* **Language:** TypeScript
* **Markup & Styling:** HTML, CSS, Bootstrap
* **Version Control:** Git & GitHub
* **Deployment:** GitHub Pages
* **Browser Storage:** LocalStorage (Favorites)
